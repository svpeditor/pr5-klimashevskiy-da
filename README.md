# Практическая работа №5. Строки, массивы, циклы и методы обработки данных

Климашевский Даниил Александрович, группа ЭФБО-07-25, вариант 4.

Консольная программа проверяет строку табеля сотрудника за рабочую неделю (часы за 5 дней
через ;) и считает сумму, среднее, количество дней с переработкой и недельную переработку.
При ошибке сообщает номер позиции, табель с ошибкой не считается. По варианту 4 дневная норма
8 часов увеличена на 25 %: переработкой считается день, где больше 10 часов.

## Сборка и запуск

Нужна Java 21 или новее.

```bash
mkdir -p out
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out ru.edu.pr02.SelfCheck
```

Или скриптом: `./run_selfcheck.sh` (macOS/Linux), `run_selfcheck.bat` (Windows).

SelfCheck сначала выполняет проверки, потом выводит отчет по каждой строке `data/sample.csv`.
Можно передать свой файл, например мои граничные значения:

```bash
java -cp out ru.edu.pr02.SelfCheck data/boundaries.csv
```

Ввод с клавиатуры (каждая строка - один табель, пустая строка - выход):

```bash
java -cp out ru.edu.pr02.TimesheetAnalyzer
```

Stream API не используется. Пакет называется `ru.edu.pr02`, как в исходном проекте.

## Что где лежит

- `src/ru/edu/pr02/TimesheetAnalyzer.java` - разбор строки, расчеты и отчет
- `src/ru/edu/pr02/SelfCheck.java` - проверки и отчеты по файлу
- `data/sample.csv` - открытый набор из задания, `data/boundaries.csv` - мои граничные значения
- `diagrams/` - activity-диаграмма и диаграмма классов (dot и png)
- `DECISIONS.md` - вариант, два решения, где цикл, граничные проверки, ответы на вопросы
- `REPORT.docx` - отчет
